# 《日噬群岛》开发路线

> 剧情见 [剧情设计.md](剧情设计.md)，怪物与声音设计见 [怪物图鉴.md](怪物图鉴.md)。
> 开发循环每一轮只做**最上面一个未完成的任务**，并按同一套流程交付：
> 实现 → 批处理重建场景 → 离线截图检查 → 把这里的状态改成 ✅ → 在「开发日志」里写一行。
> 标了 🔒 的任务需要先问过你（下载新资源、选择模型来源等），循环到这里会停下来等你答复。
> **声音是每个任务的一部分**：新加的生物、道具、交互都要同时接上音效（正式音效到位前先用程序合成的临时音效）。

- [x] ✅ 2p. **Terrain Sample Asset Pack**（用户已下载）：导入 Unity 官方地形样例包，挑选高质量地表图层替换晨星岛的草地、泥地、岩石等，用其中的草、蕨、灌木丰富林下植被，材质确认为 URP
- [x] ✅ 2z. **模块工程化**（用户要求，优先）：
  - 目录：脚本按模块归入 `Assets/_Game/<模块>/`（Core、Player、Weapons、Audio、Story、Cutscene、World、Wildlife、Rendering、Creatures），每个模块下分 Runtime / Editor；美术与生成资源保持在 Art
  - 程序集：每个模块一个 Assembly Definition，依赖单向（Core 在最底层，其余依赖 Core；Editor 程序集只在编辑器编译），缩短编译时间、防止循环依赖
  - 命名空间：统一 `Rishi.<模块>`（日噬）
  - 解耦：模块之间通过 Core 里的事件总线 / 服务接口通信，减少 static Instance 和 FindFirstObjectByType
  - 配置数据化：昼夜、天气、音效表、生物参数等改为 ScriptableObject 配置资产，策划可直接在 Inspector 里调
  - 场景生成器拆分：IslandBuilder 按地形 / 植被 / 剧情 / 声音 / 画质拆成独立步骤，可单独重跑
  - 版本管理：初始化 Git 仓库（.gitignore 排除 Library/Temp/Logs 等，大文件走 Git LFS），方便你在 Mac 上协同
  - 测试：Core 与 Story 的关键逻辑加 EditMode 单元测试（谜题判定、目标推进、存档）
  - 文档：Docs/架构说明.md，写清模块职责与依赖图
- [x] ✅ 2f. **背包系统**（用户要求，优先）：物品配置资产（名称、描述、图标、分类、堆叠上限）；玩家背包 24 格、堆叠、按 Tab 打开背包界面（分类、物品说明、使用 / 丢弃）；场景里的可拾取物品（E 拾取，拾取音效与提示）；弹药、鱼枪矛、贝壳、珍珠、食物等第一批物品

- [x] ✅ 2i. **游泳与潜水**（用户要求，优先）：水深没过胸口自动转为游泳；水面漂浮、划水，Ctrl 下潜、空格上浮，视线方向游动；氧气条（水面恢复），氧气低时心跳、视野变暗、隔着水传来三下敲击声（陈默的伏笔），耗尽后昏迷、在岸边醒来；入水 / 出水水花、划水、水下气泡和呼吸音效；水下画面：蓝绿色深度雾随深度变暗、颜色衰减、水下光柱、焦散光斑、悬浮颗粒、从水下看到起伏的水面；水下声音低通闷响
- [ ] 2o. **海底世界**（用户要求，优先；进行中：鱼、砍刀、水声已换成商店资源，珊瑚 / 海草 / 贝壳还是程序生成的占位，等写实的免费或付费资源）：真实而奇妙的海底：多种鱼（成群的小银鱼、彩色珊瑚鱼、独行的大鱼、鳐鱼，躲避玩家、群游转向）、随水流摆动的海草床与海带林、珊瑚礁（鹿角珊瑚、脑珊瑚、扇珊瑚、海葵）、礁石与沙地起伏、海胆、海星、贝壳；可收集的贝壳与珍珠；海底的阿玛拉石碑（新的线索文本）和一艘更深处的小沉船（宝箱）；海底环境声
- [x] ✅ 2y. **配置数据化 + 生成器分步**（2z 剩下的部分）：昼夜、天气、音效表、生物参数改为 ScriptableObject 配置资产；IslandBuilder 拆成可单独重跑的步骤

- [ ] 2w. **动态天气系统**：晴 / 多云 / 阴 / 小雨 / 暴雨雷暴 / 浓雾，按概率随时间切换并平滑过渡；每种天气联动云量与天色、阳光强度、环境光、雾的浓度和颜色、风力（植物摆幅）、海浪大小、体积光；下雨时有雨幕粒子、雨声、地面和岩石变湿变暗反光、水面雨点涟漪；雷暴有闪电照亮天空和延迟雷声（复用 CG01 风暴的效果）；环境声随天气变化（雨天鸟叫消失）。和恐怖玩法挂钩：夜里浓雾概率更高，每拿到一块碎片坏天气更频繁，雨夜怪物更活跃（怪物做好后接上）。调试键：按 F8 切换天气
