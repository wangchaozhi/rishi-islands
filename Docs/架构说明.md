# 《日噬群岛》代码架构

所有游戏代码都在 `Assets/_Game/`，按模块拆开。每个模块是一个程序集（asmdef），命名空间统一为 `Rishi.<模块>`。

## 模块与依赖

依赖只能单向往下走，编译器会拦住循环引用。

```
                 Builders.Editor（仅编辑器，引用所有运行时模块）
                         │
   ┌──────┬──────────┬───┴─────┬──────────┬───────────┐
   UI     Story      Cutscene  Wildlife   Rendering（独立，只依赖 URP）
   │        │          │         │
 Weapons    └────┬─────┴─────────┘
   │             │
 Player          │
   │             │
   └──► Audio ◄──┘
          │
        World
          │
        Core
```

| 模块 | 程序集 | 职责 | 主要脚本 |
|---|---|---|---|
| Core | Rishi.Core | 跨模块共享的状态和接口，不依赖任何模块 | `GameSignals`（输入锁定 / 过场中 / 碎片数 / 玩家注册），`IDamageable`，`SurfaceTag` |
| World | Rishi.World | 时间、光照、风、海面跟随 | `DayNightCycle`，`WindController`，`OceanFollow` |
| Audio | Rishi.Audio | 音效池、环境声分层、区域声 | `AudioManager`，`AmbientController`，`AmbientZone` |
| Player | Rishi.Player | 第一人称移动与脚步声 | `PlayerController`，`Footsteps` |
| Weapons | Rishi.Weapons | 枪械、手感、特效、靶子 | `Gun`，`WeaponFeel`，`FXManager`，`Target` |
| UI | Rishi.UI | 战斗 HUD | `HUD` |
| Story | Rishi.Story | 目标、笔记、谜题、宝箱、剧情 UI | `GameState`，`Interactable`，`NoteItem`，`PillarPuzzle`，`TreasureChest`，`StoryUI` … |
| Cutscene | Rishi.Cutscene | Timeline 过场与自定义轨道 | `CutscenePlayer`，`CameraPathTrack`，`SubtitleTrack`，`FadeTrack`，`StormFX` |
| Wildlife | Rishi.Wildlife | 小动物生成与行为、鸟群作息 | `WildlifeDirector`，`Critters`，`BirdsSchedule` |
| Rendering | Rishi.Rendering | URP 渲染特性 | `VolumetricLightFeature` |
| Builders | Rishi.Builders.Editor | 程序化生成场景、过场、预览截图 | `IslandBuilder`，`IslandStoryBuilder`，`CutsceneBuilder`，`IslandPreview` … |
| Tests | Rishi.Tests.EditMode | EditMode 单元测试 | `GameSignalsTests`，`DayNightCycleTests`，`SurfaceTagTests` |

## 模块间通信规则

- 同层或上层模块不直接引用彼此，统一通过 `Rishi.Core.GameSignals`：
  - 剧情 UI 打开笔记时写 `InputBlocked`，过场播放时写 `CutsceneActive`；玩家、武器、互动只读 `GameplayBlocked`。
  - `PlayerController` 启用时调用 `RegisterPlayer`；触发器用 `GameSignals.IsPlayer(collider)` 判断玩家，野生动物用 `GameSignals.Player` 找玩家。
  - `GameState` 拿到碎片时调用 `SetFragments`，昼夜系统只读 `GameSignals.Fragments`，不认识剧情模块。
- 武器只认 `IDamageable`，以后的野兽和怪物实现这个接口就能被击中，不需要改武器代码。
- Living Birds（Asset Store 包）在 Assembly-CSharp 里，模块程序集引用不到，`BirdsSetup` 用反射挂组件、用 SerializedObject 设参数。

## 新增模块的步骤

1. 在 `Assets/_Game/<模块>/Runtime/` 下建 `Rishi.<模块>.asmdef`，`references` 写上它依赖的所有 Rishi 模块（包括间接依赖）。
2. 脚本放进命名空间 `Rishi.<模块>`。
3. 需要别的模块的状态时，先考虑放进 `GameSignals` 或在 Core 加接口，不要让下层模块引用上层。
4. 在 `Rishi.Builders.Editor.asmdef` 的引用里加上新模块。

计划中的 Creatures 模块（生物框架、影嗣等）依赖 Core / World / Audio，实现 `IDamageable`。

## 命令行

```bash
# 重建晨星岛场景并离线截图（Screenshots/Island、Screenshots/Cutscenes）
Unity.exe -batchmode -quit -projectPath <项目> -executeMethod Rishi.Builders.IslandPreview.BuildAndCapture -logFile build.log
# 运行 EditMode 测试
Unity.exe -batchmode -projectPath <项目> -runTests -testPlatform EditMode -testResults results.xml
```
