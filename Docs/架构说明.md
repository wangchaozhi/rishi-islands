# 《日噬群岛》代码架构

所有游戏代码都在 `Assets/_Game/`，按模块拆开。每个模块是一个程序集（asmdef），命名空间统一为 `Rishi.<模块>`。

## 模块与依赖

依赖只能单向往下走，编译器会拦住循环引用。

```
                 Builders.Editor（仅编辑器，引用所有运行时模块）
                         │
   ┌──────┬──────────┬───┴─────┬──────────┬───────────┐
   UI     Story      Cutscene  Wildlife   Rendering（独立，只依赖 URP）
   │        │          │         │
 Weapons    └────┬─────┴─────────┘
   │             │
 Player          │
   │             │
   └──► Audio ◄──┘
          │
        World
          │
        Core
```

| 模块 | 程序集 | 职责 | 主要脚本 |
|---|---|---|---|
| Core | Rishi.Core | 跨模块共享的状态和接口，不依赖任何模块 | `GameSignals`（输入锁定 / 过场中 / 碎片数 / 玩家注册），`IDamageable`，`SurfaceTag` |
| World | Rishi.World | 时间、光照、风、天气参数、海面跟随 | `DayNightCycle`，`WindController`，`OceanFollow`，`DayNightConfig`，`WindConfig`，`WeatherProfile` |
| Audio | Rishi.Audio | 音效表、音效池、环境声分层、区域声 | `AudioManager`，`SoundLibrary`，`AmbientController`，`AmbientZone` |
| Player | Rishi.Player | 第一人称移动与脚步声 | `PlayerController`，`Footsteps` |
| Weapons | Rishi.Weapons | 枪械、手感、特效、靶子 | `Gun`，`WeaponFeel`，`FXManager`，`Target` |
| UI | Rishi.UI | 战斗 HUD | `HUD` |
| Story | Rishi.Story | 目标、笔记、谜题、宝箱、剧情 UI | `GameState`，`Interactable`，`NoteItem`，`PillarPuzzle`，`TreasureChest`，`StoryUI` … |
| Cutscene | Rishi.Cutscene | Timeline 过场与自定义轨道 | `CutscenePlayer`，`CameraPathTrack`，`SubtitleTrack`，`FadeTrack`，`StormFX` |
| Wildlife | Rishi.Wildlife | 小动物生成与行为、鸟群作息 | `WildlifeDirector`，`Critters`，`BirdsSchedule`，`WildlifeConfig` |
| Rendering | Rishi.Rendering | URP 渲染特性 | `VolumetricLightFeature` |
| Builders | Rishi.Builders.Editor | 程序化生成场景、过场、预览截图、配置资产 | `IslandBuilder`，`IslandStoryBuilder`，`CutsceneBuilder`，`IslandPreview`，`ConfigAssets` … |
| Tests | Rishi.Tests.EditMode | EditMode 单元测试 | `GameSignalsTests`，`DayNightCycleTests`，`SurfaceTagTests`，`ConfigTests` |

## 模块间通信规则

- 同层或上层模块不直接引用彼此，统一通过 `Rishi.Core.GameSignals`：
  - 剧情 UI 打开笔记时写 `InputBlocked`，过场播放时写 `CutsceneActive`；玩家、武器、互动只读 `GameplayBlocked`。
  - `PlayerController` 启用时调用 `RegisterPlayer`；触发器用 `GameSignals.IsPlayer(collider)` 判断玩家，野生动物用 `GameSignals.Player` 找玩家。
  - `GameState` 拿到碎片时调用 `SetFragments`，昼夜系统只读 `GameSignals.Fragments`，不认识剧情模块。
- 武器只认 `IDamageable`，以后的野兽和怪物实现这个接口就能被击中，不需要改武器代码。
- Living Birds（Asset Store 包）在 Assembly-CSharp 里，模块程序集引用不到，`BirdsSetup` 用反射挂组件、用 SerializedObject 设参数。

## 新增模块的步骤

1. 在 `Assets/_Game/<模块>/Runtime/` 下建 `Rishi.<模块>.asmdef`，`references` 写上它依赖的所有 Rishi 模块（包括间接依赖）。
2. 脚本放进命名空间 `Rishi.<模块>`。
3. 需要别的模块的状态时，先考虑放进 `GameSignals` 或在 Core 加接口，不要让下层模块引用上层。
4. 在 `Rishi.Builders.Editor.asmdef` 的引用里加上新模块。

计划中的 Creatures 模块（生物框架、影嗣等）依赖 Core / World / Audio，实现 `IDamageable`。

## 配置资产

可调的数值放在 ScriptableObject 配置资产里，都在 `Assets/Config/`，选中后直接在 Inspector 里改，运行中改也会立刻生效。重建场景只在资产不存在时创建默认值，不会覆盖调过的数值。菜单 `Tools/Island/打开配置文件夹` 可以定位过去。

| 资产 | 类型（模块） | 谁在读 | 内容 |
|---|---|---|---|
| `DayNight.asset` | `DayNightConfig`（World） | `DayNightCycle` | 起始钟点、一天长度、日月光照、环境光、雾、清晨薄雾、第一天放慢 |
| `Wind.asset` | `WindConfig`（World） | `WindController` | 风向、强度、阵风 |
| `Weather_Storm.asset` | `WeatherProfile`（World） | `StormFX` | 风暴的钟点、海浪、雾、风力加成、闪电间隔；动态天气（2w）会为每种天气各建一份 |
| `SoundLibrary.asset` | `SoundLibrary`（Audio） | `AudioManager` | 每个音效 id 的变体、分类、音量、音高、3D 距离 |
| `Wildlife.asset` | `WildlifeConfig`（Wildlife） | `WildlifeDirector` 和各小动物 | 数量、生成 / 回收半径、昼夜阈值、受惊距离与速度 |

- 组件上的 `config` 为空时用代码里的默认值，单元测试和临时场景不需要资产。
- 音效表由「声音」步骤扫描 `Assets/Audio/Final` 和 `Assets/Audio/Placeholder` 生成：已有的 id 只更新音频文件，保留调过的参数；新 id 按 `AudioSetup.Rules` 的前缀规则给默认值；文件被删掉的 id 会从表里移除。

## 场景生成步骤

`IslandBuilder` 把晨星岛场景分成五步，每一步生成的物体都收在场景里同名的根节点下：

| 步骤 | 根节点 | 内容 | 单独重跑（`Tools/Island/分步重建`） |
|---|---|---|---|
| 1 地形 | `[地形]` | 太阳、月亮、天空、反射探针、昼夜、地形、海洋 | 其余步骤都建在地形上，等于整座岛重建 |
| 2 剧情 | `[剧情]` | 沉船、营地、神殿、玩家、剧情系统、CG01 / CG02、特效管理 | 会换掉玩家，连带重跑声音和画质 |
| 3 地貌与植被 | `[地貌与植被]` | 溪流、海崖、红树林、树、椰子、林冠、石头、地表植物、小动物、鸟群 | 会重新生成植物网格，连带重跑画质 |
| 4 声音 | `[声音]` | 音效表、音效管理器、玩家的脚步声和环境声 | 单独 |
| 5 画质 | `[画质]` | 后处理、风、体积光、植物风动画、TAA、过场电影后处理 | 单独 |

- 每一步用固定的随机种子，单独重跑和整体重建的结果一样。
- 植被要避开的空地（出生点、沉船、营地、神殿）从场景里的剧情物体位置读出来，所以植被可以不重跑剧情单独重建。
- 分步之前生成的旧场景没有这些根节点，分步重建会提示先整体重建一次。
- 命令行：`-executeMethod Rishi.Builders.IslandBuilder.RebuildStory`（或 `RebuildNature` / `RebuildAudio` / `RebuildVisual`）。
